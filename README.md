# AI Chatbot Django Project

A Django-based AI Chatbot web application that uses a trained Machine Learning model to understand user input and provide relevant responses.

## Features

* AI-powered chatbot
* User-friendly chat interface
* Machine Learning based text classification
* Text preprocessing and tokenization
* Trained TensorFlow/Keras model
* Django web interface
* Real-time chatbot interaction
* Conversation input and response handling

## Technologies Used

* Python
* Django
* TensorFlow / Keras
* NumPy
* Pandas
* Scikit-learn
* HTML
* CSS
* JavaScript
